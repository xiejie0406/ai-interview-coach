# FEAT-QBANK-001 公开版本化题库 Feature Spec

> 文档状态：Draft；范围已获本轮编码授权，尚未提升为全局 Canonical Approved。

## 目标与非目标

目标：让访客和已登录用户在三栏学习工作台中切换 Agent 技术模块、搜索该模块题目，并在右侧直接阅读完整标准答案。题库是知识学习工具，不要求在线作答。

非目标：题目编辑/审核/发布、收藏/错题状态、回答提交、AI 反馈、参考链接展示、题目全文搜索索引、支付权益、题库内在线作答。

## 业务规则

- `BR-QBANK-01` 公开查询只读取 `PUBLISHED`、`PUBLISHED_WITH_DRAFT`、`PUBLISHED_WITH_REVIEW` 的当前发布版本。
- `BR-QBANK-02` 题目详情固定返回 `questionVersion` 和 `rubricVersion` 引用，不静默覆盖历史版本。
- `BR-QBANK-03` 未实现能力返回能力错误，不改变当前登录会话。
- `BR-QBANK-04` 关键词首版在解密后的服务端只读投影上匹配标题；题干全文检索索引延后设计。
- `BR-QBANK-05` 模块通过题目版本的 `target_roles` 分类值筛选；每个 Agent 模块首批发布 50 道题。
- `BR-QBANK-06` 详情 API 只返回题干和完整 `referenceAnswer`，不返回答题思路、回答要求或来源链接；答案包含结论、工程实现、例子、误区和验收方式。
- `BR-QBANK-07` 桌面端工作台由可收缩模块栏、可搜索题目列表和标准答案阅读区组成。
- `BR-QBANK-08` 登录用户可在当前模块原地新增公共题目；题目及基础答案对所有用户可见，不新增“我的题库”入口。
- `BR-QBANK-09` 用户编辑答案后仅写入该用户的加密答案覆盖，不修改公共系统答案；公共题库租户与用户所属租户分别校验。
- `BR-QBANK-10` 没有用户答案时直接显示系统答案且不显示“查看系统答案”；存在用户答案时优先显示用户答案，并允许临时查看系统答案。
- `BR-QBANK-11` 答案区不显示“我的答案”“系统答案”或“标准答案”标题，只展示答案正文。

## 验收条件

- `AC-QBANK-01` GET `/api/v1/questions` 返回真实发布题目列表和稳定版本元数据。
- `AC-QBANK-02` `category=RAG_DEEP` 等模块筛选各返回 50 道深入版题；可叠加标题关键词和难度筛选。
- `AC-QBANK-03` GET `/api/v1/questions/{id}` 返回题干、完整标准答案和版本元数据，不返回来源链接。
- `AC-QBANK-04` 详情页只显示标准答案，不展示答题思路、回答要求或在线作答表单。
- `AC-QBANK-05` Chrome 中可收缩模块栏、搜索题目并在同页阅读答案；已登录会话不被公开接口清除。
- `AC-QBANK-06` Chrome 可在当前模块新增公共题目，新题可由匿名公开查询读取。
- `AC-QBANK-07` Chrome 可编辑并保存个人答案；保存前无“查看系统答案”，保存后出现该按钮且无答案来源标题。

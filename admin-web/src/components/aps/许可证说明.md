# APS 可视化组件许可证说明

> 适用范围：`admin-web/src/components/aps/` 及其构建产物  
> 核对日期：2026-09-12

## 采用版本与来源

| 组件 | 锁定版本 | 版本来源 | 许可证与归属 |
|---|---:|---|---|
| DHTMLX Gantt Community | `dhtmlx-gantt@10.0.3` | [npm](https://www.npmjs.com/package/dhtmlx-gantt)、[GitHub](https://github.com/DHTMLX/gantt) | MIT；Copyright (c) 2026 XB Software |
| vis-timeline | `vis-timeline@8.5.4` | [npm](https://www.npmjs.com/package/vis-timeline)、[GitHub](https://github.com/visjs/vis-timeline) | `Apache-2.0 OR MIT`；本项目按 MIT 路径保留归属；Copyright (c) 2014-2017 Almende B.V. and contributors，Copyright (c) 2017-2019 vis.js contributors |

版本同时由 `admin-web/package.json` 和 `admin-web/package-lock.json` 精确锁定。核对依据为各 npm 包内的 `package.json`、`LICENSE.md` / `LICENSE.MIT.txt` 与 DHTMLX Community README。DHTMLX v10 构建公开 `gantt.license`，APS 运行时会检查该值必须为 `mit`；检查失败时拒绝初始化，而不是通过改写字段伪装许可证类型。

DHTMLX Community 仅用于任务甘特展示与人工调整意图，不使用其 PRO 自动排程、关键路径或资源管理能力。资源时间轴由 vis-timeline 适配器承担。

本说明用于保存版本、许可证文本和归属证据，不替代法务审查。升级任一组件时必须重新核对上游许可证、归属、构建产物的许可证标识和功能边界。

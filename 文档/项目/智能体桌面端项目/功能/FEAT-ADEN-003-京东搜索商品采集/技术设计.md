## 1. 当前范围与变更依据

核心流程：**用户在 Chrome 自行搜索并打开京东商品详情页 → 点击“采集当前商品” → 在 Aden 查看和整理已存内容 → 导出表格和图片。**

首版只处理用户当前打开、明确点击采集的商品。自动搜索、搜索结果批量翻页、自动打开详情、自动滚动、展开隐藏区块、切换规格及定时采集移出首版；不用这些行为作为当前验收门槛。用户可以手动打开多个商品逐个采集，最后批量整理和导出。

上一版搜索批量方案曾获认可；本次更具体的用户指令覆盖其首版范围，技术路线仍沿用 Chrome 扩展 + Aden + RuoYi。旧版 JD-REQ-01～06、JD-AC-01～12、JD-TASK-01～07 留在[旧版原文快照](归档/2026-09-26-搜索批量方案原文.json)追溯，不重用编号，也不作为当前待实施清单。工程目录保留既有 FEAT-ID 与路径，标题改为详情页采集，避免目录改名与失效入链。

本版新增细节为可审查草案；用户已经明确的手动详情页采集、查看、新增、删除、图片和导出目标无需重复确认。图片存储方式、缺失处理等由本设计给出候选实现，不据此声明上线就绪。

## 3. 交互设计

三张线框图及状态说明见[交互线框图](交互线框图.md)，以下定义业务行为：

1. 首次打开插件面板，连接已登录的 Aden，明确 Workspace 和默认采集库。连接、身份和来源检查完成后，后续点击无需逐次弹出流程确认。
2. 用户自行打开京东商品详情页，选择自己关心的规格，必要时自行向下浏览。插件识别页面与当前 SKU，显示标题和规格预览。
3. 点击“采集当前商品”。默认包含商品字段、已加载商品图片区块、商品内容快照；设置可排除图片或仅保存主图/轮播图/详情图中的部分分组。
4. 先提交商品和快照清单，再保存资源。进度显示“内容已保存；图片 6/8 已保存”。只有服务端完成对应持久化后才显示已保存。
5. “查看已采集商品”进入 Aden 采集库；列表支持库内搜索、状态筛选、单选/当页全选。改变筛选清空选择并提示，避免误删未显示记录。
6. 点击商品查看商品信息、图片、内容快照和版本。字段原文只读；人工备注、标签、纠错值单独保存和展示。
7. 选择商品后删除或导出。无选择时可显式选择“导出当前筛选全部”，先显示准确数量；不把“全选当前页”解释为全部结果。

Chrome 侧边面板用作稳定的当前页采集入口，申请 sidePanel 权限；打开面板本身不代表获得目标页读取权限。[Chrome sidePanel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)

## 4. “把页面存起来”的实际含义

当前产品承诺是**保存点击采集时已加载的商品内容及其图片，能够以后在采集库回看**，不是像素级克隆整个京东网页，也不保证尚未加载、未展开或另一个 SKU 的内容自动存在。

| 保存对象 | 范围与格式候选 | 回看方式与限制 |
| --- | --- | --- |
| 商品字段 | SKU、标题、价格原文/数值/条件、所选规格、参数、店铺、配送/库存原文、规范商品链接、时间 | 类型化 JSON/MySQL 字段；未显示记缺失；不把区间/券后/会员价算成成交价 |
| 商品内容快照 | 已加载商品标题、简介、参数、商品描述的有序文本与图片引用，记录区块范围、缺失原因和解析器版本 | Aden 用自有组件生成只读视图；不执行源站脚本、不自动访问原站 |
| 图片文件 | 当前商品的主图、已加载轮播图、当前规格图及已加载详情图；按来源分组并保留顺序 | 保存字节、哈希、尺寸、类型和来源记录；以后回看使用已存文件 |
| 来源与质量 | 页面实例、SKU、规格、采集时间、已识别/已加载/已保存数量、未知区块 | 明确区分“已发现图片全部保存”与“页面所有图片已发现” |

“完整”只针对本次已识别的保存范围。无法确定完整性时显示“范围未确认”；未加载的详情区块显示“未加载，可自行浏览后再次采集”。DOM 在采集期间发生 SKU/规格变化时终止并提示重新采集，不能把不同商品拼到一份记录。

默认排除登录信息、收货地址、账号昵称、购物车、客服会话、评论者个人信息、无关推荐与广告；商品内的促销及规格原文保留。页面内容是数据，不能作为 Agent 或本机命令执行。

原始 HTML/MHTML 与全屏截图不进入首版默认保存范围。Chrome 确有将标签页保存为 MHTML 的 pageCapture 能力，但该模式会扩大保存范围和权限，并需另行处理安全回看；当前不申请此权限。若以后明确需要原站完整外观，再增加独立选项和适用验收。[Chrome pageCapture](https://developer.chrome.com/docs/extensions/reference/api/pageCapture)

## 5. 图片采集与图片管理

### 5.1 从页面发现到保存文件

内容脚本只在批准的商品区块内识别图片候选；记录 imageId、分组、顺序、URL/已加载资源信息与尺寸。不能按整页 img 数量把头像、图标和无关推荐一起归入商品图，也不猜测原图链接或遍历所有变体。

实际下载在扩展受控上下文执行；仅处理本次捕获清单中、经来源策略认可的精确资源域名和 HTTPS URL。跨源读取受扩展 host 权限及源站策略约束，图片在页面上显示不代表其字节必然可获取。不能把内容脚本传入的任意 URL 当成下载授权。[Chrome 跨源请求与安全要求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)

图片 CDN 的实际域名待真实模板核对，按精确域名运行时申请；不给 *.jd.com、全部网络或任意本机地址通配。禁止下载重定向到未批准主机、本机/私网地址、非 HTTPS 协议；传给后端的是字节和受限元数据，不让后端直接抓取页面给出的任意链接。

若无法取得资源，记录失败原因；不伪造 Referer、传递京东 Cookie 或绕过拒绝。已存文本仍可用。图片 URL 只作为来源元数据；原链接失效不影响已完成保存的文件。

图片二进制校验真实 MIME、解码、尺寸和体积，首版支持经测试的 JPEG/PNG/WebP；其他类型明确标“不支持”。外部 SVG 不作为可执行内容显示。上限候选：每次 50 张、每张 10 MiB、总计 100 MiB；这是应用资源保护值，非平台安全访问阈值，超过时展示缺失清单和配置说明。

### 5.2 原始文件与整理结果

资源按 Workspace 内哈希去重；每个快照保存图片清单版本，不能因另一个商品移除图片而破坏仍被引用的资源。图片失败重试追加新的资源清单版本，不无痕改写已经导出的版本。

用户可设主图、调整顺序、从当前整理结果移除图片、恢复被移除图片及添加本地图片。原始快照保持只读；人工上传标注来源，不能冒充京东图片。物理清理只处理无任何有效引用且满足保留策略的对象，首版不提供自动永久清理。

## 6. 新增、版本、删除与导出规则

### 6.1 商品与版本

商品身份候选键为 Workspace + 平台 + 已确认 SKU；不同 SKU 分开。不能按标题相似强行合并。无法识别 SKU 时提供“手动新增/保存待核对”，使用内部 UUID，并明确无平台商品身份。

相同 SKU 再次采集时提示“新增快照版本 / 查看已有记录”，默认新增版本；原始字段按采集时间保存。连续重复点击同一个请求用 idempotencyKey 去重；用户另一次确认采集是新 captureId。人工补充用独立 revision，不修改历史观察事实。

当前展示版本取最新已提交的快照，不依赖客户端时钟排序；最新版本部分失败时保持“部分保存”，旧完整版本仍可选。手动新增至少要求标题；价格非负且使用十进制，缺失留空；图片选填。粘贴来源链接只是记录，不触发页面访问。手动创建记录不自动同已识别 SKU 合并。

### 6.2 删除与恢复

“删除”表示移入回收站，作用于所选商品及其全部快照、人工补充、图片引用；确认弹窗列出数量和影响，支持撤销/恢复。不自动永久删除，也不删除用户已下载的文件。被移除的单张图片只改变当前整理结果，可恢复；原始版本仍保留。

商品删除时使该商品的未完成采集 generation 失效，取消其后续资源入库；在途回执不能自动复活商品。回收站中相同 SKU 再次采集时提示“恢复并采集 / 取消”。批量删除/恢复返回逐项结果，部分无权限时不能笼统提示全部成功。

回收站和附件占用计入配额；达到配额时先提示停止新增，不擅自清空。永久删除、保留周期及历史导出清理策略在真实上线前落实。

### 6.3 导出

| 模式 | 内容 |
| --- | --- |
| 仅 Excel | 商品汇总、图片清单、快照说明、异常清单四个工作表；可选嵌入每商品一张已保存主图缩略图，保持体积预算 |
| Excel + 图片 ZIP | 上述 Excel、图片/内部商品ID/快照ID/安全文件名、内容快照（UTF-8 文本/JSON）、导出说明与缺失清单 |

默认导出所选商品的当前快照和人工补充值，同时保留原值/来源列；详情页可以明确导出指定历史版本。导出创建时冻结选中 ID、snapshotId、curationRevision、assetManifestVersion 和筛选条件，不边生成边使用最新版本。

生成时和下载时检查权限与回收站状态：若商品被删除或权限撤回，拒绝该旧导出并提示重新选择；已经下载的文件无法远程撤回。导出不触发源站访问，不补抓缺失图片。缺失或用户移除的图片分别列明，已移除图片默认不入包。

Excel 中 ID 按文本，金额按十进制数值并保留价格原文，页面字符串不得生成公式。ZIP 用内部 ID 和规范文件名生成路径，禁止路径穿越；不导出 Cookie、签名查询参数或远程临时凭据。Excel 单独导出时不承诺相对图片路径可用；ZIP 清单使用包内相对路径。

## 7. 架构、权限与数据归属

当前已有 Electron/Vue 壳、RuoYi/MySQL 中心控制面和合成 Runner；COL 真实连接器仍未实现。沿用现有边界：

    用户当前详情页
        → Chrome MV3 内容脚本与侧边面板
        → Native Host（消息/字节分片校验）
        → Aden Electron 主进程（登录与受限 IPC）
        → RuoYi ruoyi-aden（任务、商品、版本、授权、导出）
        → MySQL 元数据 + 受控附件存储

MySQL 仍是唯一业务数据库；图片/内容附件使用既有文件存储抽象，本地测试可用受控数据目录，正式环境由项目既有存储方案承载，不能把安装目录当业务存储。Electron 仅持有可重建缓存及限额待传暂存；Python/扩展不拥有第二套任务或商品真相。

候选扩展目录仍为 frontend/desktop/aden-collector-extension，Native Host 仍为 aden-runner 中隔离的打包入口。复用 CORE 任务ID、审计、幂等和会话，不伪造 simulator 已具备真实采集能力。

权限路线回到用户手动触发的 attended-activeTab：MV3 使用 activeTab、scripting、storage、sidePanel、nativeMessaging。点击工具栏取得页面临时访问权限后，在面板点击采集；若当前页授权已失效，则明确提示再次点击工具栏授权，不偷偷升为全站常驻读取。图片 CDN 权限按 5.1 单独申请。跨域导航/标签关闭/撤权使页面捕获失效。[Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)

不申请 cookies、debugger、浏览历史、pageCapture 或全站权限。解析代码随扩展版本分发，不远程执行代码。Native Host 当前用户注册、精确扩展 ID 的 allowed_origins、当前用户 ACL 命名管道及配对撤销机制沿用前版路线；开发和发布扩展 ID 分离。连接 UUID 不等于 Chrome profile 或京东账号证明。

前端无权仅凭自报 workspaceId 修改数据；RuoYi 校验用户、Workspace、产品对象和操作权限。候选权限 collection:read/capture/create/edit/delete/restore/export 与角色成员关系共同生效；资源下载也需鉴权。账号退出/Workspace 切换立即停止旧空间新捕获，旧暂存隔离，不传入新空间。

## 8. 数据模型与协议草案

所有名称为设计候选，尚无 DDL 或已发布契约：

| 实体 | 权威内容和一致性 |
| --- | --- |
| CollectionItem | workspaceId、平台、SKU/内部 UUID、当前快照指针、deletedAt、version；唯一商品身份 |
| CaptureSnapshot | captureId、coreTaskId、generation、tab/documentId、SKU/规格、时间、来源、字段、内容区块及完整性；提交后事实只读 |
| AssetManifest / Asset | 快照关联、分组/顺序、资源版本、字节哈希、大小、类型、存储键、逐项保存结果 |
| ItemCuration | 人工补充值和图片整理绑定 itemId + snapshotId；商品级备注/标签独立；主图、排序/排除集合以资源 ID 引用，乐观锁 revision，来源可追溯 |
| ExportJob | 选中商品与所有固定版本、过滤条件、状态、文件、到期时间及权限记录 |
| SourcePolicy | 详情页/资源来源、字段、用途、资源配额、有效期和保留策略；继承既有 COL 治理 |

商品删除、指针更新、重复 SKU 判定在事务内完成。附件按临时上传 → 校验 → 原子提交元数据关联的步骤保存；中断文件不作为已保存资源，孤立临时文件按专门暂存策略清理。撤权后清理本机待传内容；不删除其他工作空间的缓存。

候选 API 位于 /api/v1/aden/collection/：captures/prepare、captures/{id}/commit、assets 分片/完成、items 查询/手动创建、curation 条件更新、trash/restore、exports 创建/下载。机器契约实施时进入 contracts/aden；本文件不冒充正式 OpenAPI。

控制消息包含 protocolVersion、messageId、captureId/coreTaskId、workspaceId、deviceId、connectionId、generation、sequence、nonce、expiresAt、payloadHash。服务端签发票据，Native Host 与服务端均校验；类型白名单不接受 shell、任意抓取 URL 或页面提供的可执行指令。

控制包候选上限 256 KiB；图片/快照正文走独立有界分片协议，原始二进制分片 128 KiB，编码后整包仍校验上限，包含 uploadId、offset、总大小与哈希。ACK、背压、幂等和断点均由服务端确认，不能把多张图塞入一个消息。Chrome Native Messaging 的平台限制需要在协议测试中覆盖。[官方协议说明](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging)

## 9. 保存状态、故障与恢复

快照持久化状态与 CORE 任务状态分开：未保存 → 保存中 → 已保存 / 部分保存 / 失败；每张图片还有独立结果。实现时将捕获执行映射到 CORE 的现有状态和 allowedCommands，不另立任务真相。

| 情况 | 行为与恢复 |
| --- | --- |
| 页面导航、SKU/规格变化 | 按 documentId 与商品指纹重验；变化则终止混合捕获，提示重新点击 |
| 侧边面板关闭/Worker 回收 | UI 关闭不等于成功或取消；恢复查询服务端 capture 状态和游标。丢失尚未持久保存的内容时明确重采，不凭内存状态报成功 |
| 桌面/API 断开 | 显示“尚未保存到采集库”；可在当前用户受限目录保留已捕获的暂存内容，默认最长 24 小时且限额 100 MiB，恢复前确认身份/权限，过期提示重新采集 |
| 单张图片失败 | 其余字段与文件保留；重试仅针对失败资源。过期 URL/拒绝提示用户自行打开页面重采 |
| 登录/验证码/403/明确限制 | 停止对应采集，不自动处理挑战或继续请求；用户可保留已经保存的部分 |
| 可观测 429 | 继承上游 BR-COLLECT-02 的有限等待规则；无法可靠识别 HTTP 状态时只记录可见失败，不编造状态 |
| 用户停止资源保存 | 停止新资源请求，保留已确认部分并标记取消项；不删除整个商品 |
| 保存过程中删除商品 | 失效 generation，拒绝迟到回执；不得自动恢复被删除记录 |
| 同时编辑人工补充 | If-Match/revision 冲突返回当前版本，提示重载或重新编辑，不覆盖他人结果 |
| 存储配额不足 | 已存内容保持可读，停止新写入，显示占用和处理入口，不自动永久删除 |

保存已加载 DOM 本身可以不新增源站请求，图片文件下载可能产生新请求。用户手动发起不等于不会触发验证，不承诺降低封控概率；源站允许范围与约定仍需核对，不实现反检测或限制规避。

## 10. 安装、验证与回退

沿用当前用户范围的 Aden 安装包，Native Host 随安装器提供独立可执行文件；用户安装/启用 Chrome 扩展。开发扩展与发布扩展 ID、Host 名称和测试目录独立，不覆盖其他任务环境。

协议维护扩展/Host/桌面/后端兼容矩阵；不兼容时禁用采集并给出升级提示，不退回自动脚本访问。升级/卸载保留业务附件数据，删除程序不等于删除采集库。关闭 COL 开关后既有 CORE 合成任务继续可用。迁移先增加兼容表/字段，不改变其他项目商品主数据。

实际验收必须使用安装版，不只跑开发服务：连接 → 用户打开合成详情页 → 采集 → 桌面回看 → 关闭源页后查看图片 → 新增/删除/恢复 → Excel/ZIP 导出回读。然后在已核对范围内单独进行京东真页试点；合成页面不能证明真实模板或来源权限可用。

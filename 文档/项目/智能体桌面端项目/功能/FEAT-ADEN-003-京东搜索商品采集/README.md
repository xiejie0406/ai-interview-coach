## 1. 当前交付目标

**自己搜索 → 自己打开详情页 → 点击采集 → 管理已采集商品与图片 → 导出。**

首版提供 Chrome 采集面板和 Aden 商品库。保存商品字段、已加载商品内容快照、可取得的图片文件；支持版本回看、手动新增/补充、删除到回收站并恢复、Excel 与图片 ZIP 导出。自动搜索、翻页、详情页打开、滚动和切规格不在当前首版。

评审顺序：

1. [交互线框图](交互线框图.md)：三张图展示采集入口、商品库、整理和导出。
2. [技术设计](技术设计.md)：需求、字段/图片、保存语义、协议、异常和 12 项验收条件。
3. 本页任务计划：唯一实施任务源；实现及验证进度见任务状态与[验收清单](验收清单.md)。

已有技术路线保持 RuoYi/MySQL 唯一中心控制面，Electron 展示，Chrome 扩展读取用户当前页面，Native Host 连接安装版。COL 已新增后端、桌面与扩展源码，实际可用范围以安装版证据为准。

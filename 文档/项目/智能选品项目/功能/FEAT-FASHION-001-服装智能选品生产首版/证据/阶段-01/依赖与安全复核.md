# IMP-01 依赖与安全复核

> 文档类型：阶段证据；版本：1.0；文档状态：Approved  
> Feature：FEAT-FASHION-001；实施阶段：IMP-01  
> 复核日期：2026-09-13；复核人：Codex  
> 结论：Pass（存在已列明、未由 Fashion 使用的继承 Moderate 风险）

## 1. 范围与结论

本次只复核 IMP-01 新增或为其升级、锁定的依赖和安全边界，不代表真实 Provider、数据库、对象存储、采集端或多实例部署已经完成。`package-lock.json` 与 `uv.lock` 已落盘；Maven 版本由父 POM 和 Spring Boot 4.0.6 BOM 管理。

- 新增依赖未发现 High/Critical 漏洞，许可证均为 MIT、Apache-2.0 或 BSD-3-Clause。
- Python `pip-audit` 返回 0；只跳过不可在 PyPI 审计的本地包 `fashion-ai-runtime 0.1.0`。
- Admin 全量与 production-only 审计均只剩既有 `echarts 5.6.0` 的 1 个 Moderate；High/Critical 门返回 0。
- 旧 `vite-plugin-svg-icons` 构建链已被本地零额外依赖 SVG sprite 插件替换，原 6 个 High 不再存在。
- `echarts` 只由现有 Redis 监控页使用，Fashion 本阶段不消费它。修复版 6.1.0 是大版本升级，需对现有图表样式和交互单独回归，因此本阶段不以 `npm audit fix --force` 扩大修改范围。进入发布候选前仍须关闭或由实际发布负责人接受该风险。

## 3. 安全边界复核

| 控制 | 结果 | 证据边界 |
| --- | --- | --- |
| Java ↔ Python HMAC | Pass | HMAC-SHA256、至少 32 字节 Base64/Base64URL key、active/previous、300 秒时钟窗、600 秒 nonce、常量时间比较及双向固定向量 |
| 认证/授权语义 | Pass | 无效或重放为 401；有效身份但 service/audience 无权限为 403；nonce 容量耗尽为 429 |
| 重放保护 | Pass（单进程） | Java/Python 均为有界 map＋到期最小堆；按 `service_id + nonce` 跨 key 防重放；多实例前必须替换 |
| 正文上限 | Pass | ASGI 在 FastAPI/Pydantic 解析前累计实际字节；缺失、伪小、分块、超大或畸形 `Content-Length` 均不能绕过 413 |
| 关联与追踪 | Pass（无采集端） | 必需 request/correlation/trace headers、正文 ID 一致性、W3C 传播、低基数路由标签、白名单日志；未配置 exporter/collector |
| 浏览器边界 | Pass | Admin 仅使用相对 `/fashion` Java API；生产 `dist` 敏感模式命中 0，不含 Python URL、服务签名头或 Provider Secret |
| Provider/数据 | Pass（保持关闭） | Provider 固定 disabled；Python 不含数据库依赖或正式副作用；本阶段没有数据库、migration 或业务 Controller |

## 4. 实际环境与命令结果

环境：Windows 11；Node 24.15.0；npm 11.12.1；JDK Temurin 21.0.10（`javac` target/release 17）；Maven 3.9.15；Python 3.12.4；uv 0.11.18。

主要通过结果：

- `mvn -f platform-backend/pom.xml -pl ruoyi-fashion -am test`：25 tests，0 failure/error。
- `mvn -f platform-backend/pom.xml -pl ruoyi-admin -am -DskipTests package`：15 reactor modules，BUILD SUCCESS。
- `npm --prefix admin-web run typecheck`：Pass。
- `npm --prefix admin-web run test:unit`：2 files / 20 tests Pass。
- `npm --prefix admin-web run build:prod`：2556 modules，Pass。
- `npm --prefix admin-web run test:e2e:fashion`：Chrome 1/1 Pass；未启动 Java 时 `/captchaImage` 代理出现预期 `ECONNREFUSED`，不影响边界断言。
- `uv ... pytest ... fashion-ai-runtime/tests`：113 passed / 1 Starlette TestClient 弃用 warning。
- Ruff：Pass；Pyright strict：0 errors。
- `uvx pip-audit --path fashion-ai-runtime/.venv/Lib/site-packages`：No known vulnerabilities；跳过本地不可发布包本身。
- `npm audit --audit-level=high` 与 production-only 同口径：退出码 0；报告 1 Moderate、0 High/Critical。
- Runtime OpenAPI 重新导出前后 SHA-256 均为 `4415D4683481DADE5237DCF80D9797115561EABFAC15ED3E012E75DB741B9E3F`。

失败与修正记录：

- 首次 Python 命令未限定测试目录，从仓库根误收集 Aden/Runner 用例并产生 4 个导入错误；修正为显式 `fashion-ai-runtime/tests` 后通过。该次失败不属于 Runtime 用例失败。
- 首次 Ruff 发现 6 个测试 import 排序问题；机械修复后通过。
- 首次 Java 源码编译遗漏 `Base64` import；补齐后通过。
- 认证语义复核把 Java 403 从旧 401 断言中分离；第一次回归暴露旧测试辅助函数仍硬编码 401，修正后 25/25 通过。
- 首次 Maven `dependency:tree` 过滤参数被 PowerShell 逗号解析破坏；用单引号传递完整 `-Dincludes` 后通过。
- 一次 Python 许可证元数据内嵌命令因 PowerShell 引号错误未执行；改用只读标准 `METADATA` 后取得上表结果。
- Admin Fashion 与 APS Vitest 曾并行运行造成 worker startup timeout；分别顺序执行后 Fashion 20/20、APS 10/10 均通过。

## 5. 剩余限制与恢复条件

- 当前机器只有 JDK 21，构建目标为 Java 17；尚未用真实 JDK 17 runtime 执行。进入候选环境前须在 JDK 17 CI/环境复跑。
- replay store 仅单进程；多副本部署前必须换成跨实例原子 TTL 存储或批准的 workload identity 方案。
- OTel 无 exporter/collector；不得表述为监控已上线。
- `echarts 5.6.0` Moderate 尚未关闭；单独升级 6.1.0 时需回归现有 Redis 监控图表和 v6 主题/布局变化。
- 二进制下载的 HTTP 200 业务错误解析留到实际下载客户端所在的 IMP-09；当前没有 Fashion 下载调用。
- 未连接 MySQL、未执行 migration、未启用 Provider、未使用真实账号/数据、未部署或发布。

以上限制不否定 IMP-01 的单实例工程与契约基线，但会分别阻断多实例、真实 Provider、候选环境或发布结论。

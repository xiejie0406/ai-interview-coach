## 1. 本阶段修正

生产候选核查发现并修正三项与 PRD 容量基线不一致的实现、一项真网络协议缺陷和两项完整 Spring 容器装配缺陷：

1. 商品及价格/库存导入解析器原上限为 5,000 行，现统一为 100,000 行；超限仍在业务写入前拒绝。
2. 上传限制统一到 PRD：数据文件 30 MB、单图 20 MB、ZIP 压缩包 200 MB、最多 1,000 个条目、解压总量 500 MB、最大解压比 100；新增高压缩比 ZIP 拒绝测试。
3. PPTX 增加商品原图清单及自动续页，相同对象引用去重；容量样本的 40 张商品原图和 4 张采用图均成为实际图片形状，不以未读取的输入或空壳文件计时。
4. JDK `HttpClient` 默认尝试 cleartext h2c 升级时，Uvicorn 会收到 upgrade 警告并把带正文的 Java POST 解析为空正文，导致 HMAC 正文摘要不一致而返回 401；Java→Python adapter 已固定 `HTTP_1_1`，并新增真实 socket 回归防止仅靠组件/固定向量测试漏检。
5. Spring Boot 4 提供的是 Jackson 3 `tools.jackson.databind.ObjectMapper`，Fashion 原实现仍注入 Jackson 2 databind/core 类型，导致完整应用没有可用 Mapper Bean；现已统一迁移到平台 Jackson 3，并移除旧 `jackson-datatype-jsr310` 直接依赖，annotation 保持平台兼容包。
6. `@Repository` 异常翻译和 `@PreAuthorize` 方法安全在当前平台使用类代理；两个 Repository 和两个 Controller 声明为 `final` 时无法生成 CGLIB 子类。已只对这四个受切面代理的 Spring Bean 移除 `final`，不改变接口或业务行为。

这些修改不新增表、不改变 Java/MySQL 权威边界，也不启用真实 Provider。

## 5. 上线就绪评估

当前判断为 **NotReady / NotReleased**，不是实现失败。代码、构建、迁移、权限、容量、安全和本地恢复已经形成候选基线，但以下必需输入尚不存在：

- 生产候选环境标识、CPU/内存、MySQL、对象存储、域名/TLS、网络拓扑、Secret 来源、备份位置和负责人员；
- 明确选定的文本/视觉 Provider、账号、数据条款、80 个授权商品/图片、40 个试点任务、人民币费用上限和停止条件；
- 目标 PowerPoint/WPS 版本及候选环境下载链路；
- 实际 UAT 人员、角色、时间和接受决定。

上述输入统一填写到 `platform-backend/ruoyi-fashion/scripts/candidate-validation-manifest.example.json` 的副本中，只写秘密管理引用，不写账号口令、Token 或密钥值。执行 `test-candidate-validation-preflight.ps1` 只做离线检查并输出清单 SHA-256、差距和固定安全边界；只有 `ready=true` 才表示输入齐备，仍不自动连接环境、写库、调用 Provider、执行 UAT 或发布。

候选环境配置至少应逐项回读：Fashion MySQL 限定数据源、数据库名与 migration；客户联系人 AES-GCM key；Java↔Python active/previous HMAC key、service/audience、nonce 多实例共享策略；对象存储 bucket/前缀/加密/生命周期；三个 Worker 开关、租约、并发和重试；库存时效、折扣/税口径、AI 月度预算；异常阈值与通知渠道；备份保留及恢复账号。Secret 只从环境 Secret 来源注入，不写 `sys_config`、源码、前端或证据。

停止条件包括：跨客户/成本越权；migration 与 16 表基线不一致；确认报价无法复算；旧 fence 可提交副作用；Provider 费用或结果 unknown 且无法按原键回查；任一品类真实视觉试点未达到 8/10；四品类缺件或关键款色标识错误被采用；备份恢复后当前值、导入证据、报价、素材引用或文件摘要不一致；候选环境 P95/批次/PPT 超门且无批准例外。

恢复顺序为：停止新写入与 Worker 领取，保留失败现场和关联 ID；确认最近可用数据库备份与对象版本；恢复到隔离目标并运行 migration validate；核对 T01～T16、商品当前值、导入前后值、报价三层、素材引用和文件摘要；只在核对通过后切换流量并恢复 Worker。重新部署不能替代数据恢复。

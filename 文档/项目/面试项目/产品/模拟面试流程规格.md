# 模拟面试流程规格

> 文档状态：Draft；Feature：FEAT-INTERVIEW-001；版本：v0.1；阶段：3 功能规格

## 1. 首版流程

配置岗位与方向 → 选择 5 题短练习或 15 分钟模拟 → 展示题目 → 用户文本回答 → 必要时追问 1–2 次 → 提交 → 生成逐题反馈。

## 2. 必须覆盖的状态

空态、准备中、进行中、等待回答、追问中、提交中、报告生成中、完成、失败、主动结束和恢复。

## 3. 业务边界

追问必须与回答相关；证据不足时明确说明；用户可跳过、结束和重试；失败不得丢失已确认回答；一次训练不展示不可解释的综合总分。

## 4. 验收

固定样例验证正常回答、泛泛回答、空回答、重复提交、超时、刷新恢复和报告生成失败。

# 界面改版与视觉验收规格

> 文档状态：Draft；Feature：FEAT-INTERVIEW-001；版本：v0.1；阶段：4 原型验证准备

## 1. 当前问题

首页入口过多；题库筛选复杂但推荐不明显；面试页主操作不突出；报告偏重分数、缺少原话证据和下一步动作；移动端信息层级不稳定。

## 2. 改版目标

新用户 30 秒内找到下一步；每页只有一个主 CTA；先展示岗位推荐再展开筛选；报告先结论后证据；所有关键流程具备空态、加载、错误、拒绝、取消和完成状态。

## 3. 核心页面

首页、题库首页、题目详情、训练配置、面试进行中、反馈报告、训练历史。

## 4. 视觉与可用性验收

检查信息层级、主 CTA、响应式布局、键盘操作、读屏标签、错误可恢复性和移动端触控区域；未完成原型评审前不进入 UI Approved。

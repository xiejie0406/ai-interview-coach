# 题库内容与质量规格

> 文档状态：Draft；Feature：FEAT-INTERVIEW-001；版本：v0.1；阶段：3 功能规格

## 1. 首版题库边界

| 方向 | 目标题量 | 题型 |
|---|---:|---|
| Java 后端基础与工程 | 80 | 知识、故障排查、设计取舍 |
| RAG 与检索 | 40 | 原理、方案设计、效果评估 |
| Agent 与工具调用 | 40 | 工作流、工具、记忆、失败恢复 |
| AI 系统设计 | 30 | 架构、成本、延迟、可靠性 |
| 项目表达与行为面试 | 30 | 项目闭环、难点、取舍、失败 |

## 2. 合格题目字段

稳定 ID、岗位、方向、级别、难度、题干、考察目标、参考答案要点、追问模板、Rubric、常见错误、参考来源与访问日期、版本、审核人、发布状态。

## 3. 质量规则

每题至少经过内容审核；不得重复考察同一能力；答案必须能追溯来源；过时技术需标注版本；低质量或争议题进入隔离状态，不直接推荐。

## 4. 题库验收

首批样本完成覆盖率、重复率、来源完整率、专家可评分率检查；题量不足时优先补齐岗位核心能力，不以生成数量代替审核。

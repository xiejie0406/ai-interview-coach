## 2. 若依集成边界

面试项目使用若依账号、认证、角色、菜单和权限能力，但题库、面试、语音、评测、学习与计费仍是面试业务。项目内的若依集成设计见[`若依身份与后端单体收敛设计`](架构/若依集成/若依身份与后端单体收敛设计.md)；跨目录导航见[`若依框架—面试项目集成索引`](../../若依框架/面试项目集成索引.md)。

若依上游对照工程和其他项目不得从本项目文档推导自身的数据库或业务模块边界。

## 1. 一次内部验证的用户路径

固定中文中级 Java / 技术模拟场景 → 本地设备检测 → 准备首题 → 明确开始 → 听题 / 看题 → 录音 → 我说完了 → final 文本确认 → 提交保存 → 一次有依据的追问或结束 → 内部结果摘要。

S1 内部结果摘要只列提交答案、追问、结束状态和关联 ID，不伪造正式评分报告。S2 扩全场，S3 才展示分项报告；用户设置页不提前显示尚未完成的 HR、教练或购买操作。

```text
准备页：中文中级 Java · 技术模拟 · 内部验证
  [检查麦克风] [播放测试]    结果：待检查 / 可用 / 失败
  说明：测试录音不保存；语音不可用时可改文字
  [准备面试]                   [文字模式]

首题就绪：只显示“问题已就绪”和开场说明；确认前不显示完整题面
  尚未开始计时 / 尚未使用场次
  [开始作答]                   [退出]

面试室：技术面试官 · 项目实践     有效训练剩余时间
  当前题：怎样避免重复请求造成重复创建订单？
  字幕：临时内容（尚未提交）
  [我说完了]  [停止朗读]  [暂停]
  次级：[再听一次] [文字回答] [结束本场]

确认页：请确认本次回答
  原始识别文本 / 可编辑框 / 疑似识别问题
  [确认提交]                  [重录] [返回继续编辑]

已保存：回答已保存，正在准备下一问
  [暂停] [结束本场]           提交按钮禁用，避免重复意图

结束对话框：当前有未提交的回答
  [先提交再结束] [舍弃本次未提交内容并结束] [返回]
```

首题实际题面从 presentation 确认后返回并显示，确认前用户快照正文为 null，TTS 内容也不可领取，避免只靠界面隐藏。客户端先确认渲染容器 / 播放能力就绪，再请求开始；不能以预取完整题面作为就绪条件。服务器记录的是用户明确开始及客户端可呈现声明，不是证明用户实际听清。

## 2. 状态矩阵

| 状态 | 可见反馈 / 主动作 | 恢复 / 退出 | AC |
| --- | --- | --- | --- |
| 首次 / 无资料 | 固定内部样例，未配置不得伪装生成 | 返回配置 / 文字 | 01 |
| 设备未授权 / 拒绝 | 说明麦克风用途 / 拒绝原因 | 主动重试、文字继续 | 02 |
| 首题加载 / 外部失败 | 正在准备；失败给关联编号 | 重试受预算限制，退出释放预留 | 02、15 |
| 首题就绪但未开始 | 告知开始计时与使用次数 | 开始 / 退出 | 02、14 |
| 录音 / 临时字幕 | 正在听；字幕尚未提交 | 结束录音、暂停、文字 | 03 |
| ASR 等待 / 超时 | 已停止录音，正在识别，训练计时暂停 | 超时重录 / 文字 / 暂停 | 03、07、15 |
| final / 识别疑问 | 编辑与明确确认；无置信度也要确认 | 重录 / 不提交退出 | 03 |
| 提交结果未知 | 正在确认保存结果；不说“已保存” | 原 key 回读，保留输入 | 04 |
| 已保存 / 模型等待 | 回答已保存，正在准备下一问 | 暂停 / 结束 | 05、08 |
| TTS 不可用 / 被打断 | 保留题面；停播不是跳题 | 重听 / 文字 / 回答 | 02、08 |
| 412 或标签页冲突 | 进度已变化，先刷新快照 | 保留草稿作对照，禁止盲覆盖 | 04、12 |
| 401 / 403 / 404 | 身份过期 / 处理同意缺失 / 资源不可用 | 停录音，登录 / 权限入口 / 返回 | 12 |
| 暂停 / 断线 | 本地已停，服务端状态确认中或已暂停 | 明确继续；不自动开麦 / 重播 | 08 |
| 到期待确认 | 停止新增内容，只能确认冻结文本 | 确认 / 排除；显示60s窗口 | 07、09 |
| 完成 / 取消 | S1 显示内部链路摘要，无评分报告 | 返回，禁止重新答已冻结题 | 09 |

## 3. 前端与 UI 交接

路由沿用现有面试设置 / 房间，新版本通过明确入口标识与服务端授权映射，刷新先 GET Snapshot。表单草稿仅当前页面内存；不能显示虚假的“草稿已保存”。仅收到 answerVersionId 后展示保存成功。

复用现有 Portal / Element Plus 组件和样式，不全局换主题；首屏一个主动作，取消与舍弃分别标明影响。小屏顺序为题面→状态→输入→操作，状态不可只靠波形或颜色。模态关闭返回原焦点；键盘能完成采集、确认、暂停、结束；final / 错误用适度 aria-live。

视觉资产映射在 S1 前端任务开始前记录实际 CSS / token 路径及状态基线。本文是文字线框，未输出 Figma、截图或可交互 Mock；视觉 / 可访问性评审待进行，不以文档可读称 UI 验证通过。

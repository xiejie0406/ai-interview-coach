```text
你负责 AI Interview Coach 的核心 application service 候选实现。

项目目录：
D:\2025Ai\26-05-23\ai-interview-coach

先完整读取用户级 AGENTS/spec、项目 AGENTS、docs/specs/README.md、Feature 控制页、任务清单.md、实施技术契约候选包.md、代码落地就绪审查.md。

只允许编辑：
- backend/interview-application/src/main/java/com/aiinterviewcoach/application/identity/**
- backend/interview-application/src/main/java/com/aiinterviewcoach/application/catalog/**
- backend/interview-application/src/main/java/com/aiinterviewcoach/application/practice/**
- backend/interview-application/src/main/java/com/aiinterviewcoach/application/interview/**
- backend/interview-application/src/main/java/com/aiinterviewcoach/application/billing/**
- backend/interview-application/src/main/java/com/aiinterviewcoach/application/platform/**
- backend/interview-application/src/main/java/com/aiinterviewcoach/application/governance/**

禁止修改：
- domain、adapters、boot、contracts、frontend、POM、测试代码、docs/product、docs/phases/phase-*.md。

目标：
- 使用现有 domain aggregate 和 port，补齐 use case/internal service。
- 每个入口都必须校验 tenantId、principal、ownerUserId、version/ETag 或 commandVersion。
- Interview session command guard 必须匹配状态机：create/start/submit/recover/cancel/finish/report trigger。
- Billing 必须支持 entitlement check、reservation、commit/refund、usage ledger、cost ledger 端口调用形态；不接真实支付。
- Governance 必须支持 audit append、privacy deletion request orchestration、admin permission decision port 形态。
- Idempotency 和 job receipt 必须进入命令边界；重复请求返回已知 receipt，不重复修改聚合。
- 失败必须返回 application/domain exception，不吞错、不写 fallback success。

建议补齐：
- internal/DefaultRegisterAccount、DefaultLogin、DefaultLogout、DefaultGetCurrentAccount、DefaultUpdateProfile（只以当前 identity.yaml 为准，不猜造 refresh/账号找回 endpoint）。
- internal/DefaultListCatalog、DefaultCreatePracticeDraft、DefaultSubmitPracticeAnswer。
- internal/DefaultCreateInterviewPlan、DefaultGetInterviewPlan、DefaultCreateInterviewSession、DefaultHandleInterviewCommand。
- internal/DefaultCheckEntitlement、DefaultReserveEntitlement、DefaultCommitUsage、DefaultRefundReservation。
- internal/DefaultRequestPrivacyDeletion、DefaultAppendAuditEvent。
- 各包 repository/port/dto/command/result 的缺口。

注意：
- 不新增公共 REST/OpenAPI；只补 application 内部边界。
- 不反向依赖 adapters/boot。
- 不硬编码供应商、金额小数位、模型名、真实政策版本。
- 不记录敏感正文到异常或 toString。

只读静态检查：
- import 可定位。
- application 只依赖 domain 和 application 公共包。
- 无 PaiCLI 引用。
- 无敏感 toString。
- 用例和端口名称清楚标明 NotRun 候选状态。

不得运行构建、测试、服务、迁移、Git 或外部调用。

交接：
- 已改文件。
- 已补用例清单。
- 仍缺的 REST/SSE/WebSocket 或前端契约。
- NotRun 证据状态。
```

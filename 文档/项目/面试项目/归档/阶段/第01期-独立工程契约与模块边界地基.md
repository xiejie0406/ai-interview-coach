## 1. 本期为什么存在

新项目没有代码地基。先确定五个物理 Maven module、逻辑域包、契约、迁移、配置与测试支撑，后续纵切才不会各自搭建 Spring、HTTP、错误和数据库框架。纯底层期的必要性在于建立可编译依赖门和可启动的最小可观察壳。

## 2. 用户可见目标

未来开发环境中可打开一个独立产品壳，看到公开首页占位、统一错误页和服务健康状态；不出现 PaiCLI 品牌、接口或配置。

## 3. 技术学习目标

掌握 Java 21 多 module、六边形依赖、Spring Boot 装配、React 路由、OpenAPI/AsyncAPI、Flyway 与 Testcontainers 的职责差异。

## 4. 范围

根聚合 POM、domain/application/adapters/boot/test-support、React/Vite 壳、统一错误信封、健康接口、配置校验、Flyway 基线、模块边界检查计划、契约索引与本地环境说明。

## 5. 非目标

不实现账号、题库、Agent、语音、业务表、真实 Provider、生产 CI/CD 或云部署；不创建 PaiCLI 依赖/复制源码。

## 6. 前置决策

DEC-002、019–024、021–023、027、032、033。版本只建立兼容性决策任务，不在 Phase 猜定 Spring Boot/Modulith/Node 版本。

## 7. 前置期次和依赖

无前置 Phase；实施前需 Approved PRD/原型/设计、Feature `任务清单.md` 和开发/测试/构建授权。

## 8. 涉及的 REQ/BR/AC/DES

横切支撑 REQ-01–12；DES-MOD-01–12、DES-API 基础、DES-DATA 迁移、DES-SEC 配置。该映射不声称需求已实现。

## 9. 本期完整功能点

- 五 module 单向依赖与逻辑域包约定。
- `/api/v1/health`、标准错误、correlation ID、配置失败快速退出。
- 前端 public/auth/workspace/admin 路由壳、Error Boundary、AsyncState。
- PostgreSQL datasource/Flyway 约定和空基线；统一事件信封。
- test-support 的 builder/fake/container 入口与敏感配置红线。

## 10. 正常流程

Boot 读取无秘密的本地配置→Flyway 检查/迁移→应用就绪→前端访问健康接口→显示服务可用与空首页壳。

## 11. 空态、错误、拒绝、取消和恢复

无业务数据时展示产品空壳；缺配置/数据库不可达时 Boot 明确失败；未知路由/接口返回统一 404；未经认证进入工作台重定向登录；启动可取消；修复配置后重新启动，不产生业务数据恢复语义。

## 12. 后端模块

`interview-domain` 无框架；`interview-application` 定义 `ClockPort/IdGenerator`；`interview-adapters` 放 `CorrelationIdFilter/ApiErrorHandler`；`interview-boot` 放 `InterviewCoachApplication/ApiConfiguration`; `interview-test-support` 放 fake/container 支撑。

## 13. 前端页面和组件

路由 `/`、`/auth/login`、`/app`、`/admin`；`RootLayout`、`RootErrorPage`、`AsyncState`、`PermissionDenied`、`api/client.ts`。业务页面均为明确占位，不伪装完成。

## 14. 数据实体、约束和迁移

仅建立 Flyway history 与 schema/role 约定；不建业务实体。`aic_migrator` DDL、`aic_app` DML 的建议进入部署设计；migration 命名、校验和 expand/contract 规则可检查。

## 15. REST/SSE/WebSocket/API 或事件

计划创建 `GET /api/v1/health`、`ErrorEnvelope v1`、`EventEnvelope v1`；SSE/WS 只定义基础信封与认证占位，不开放业务 endpoint。

## 16. Agent/Prompt/Provider

只预留 application port 目录和 Provider 配置接口；不创建实际模型调用、Prompt 或供应商依赖。

## 17. 安全与隐私

前端无 Provider Key/长期 token；精确 CORS/同源方向；Secret 仅环境/Secret Manager；日志 redact filter 从第一期存在；示例配置只有键名。

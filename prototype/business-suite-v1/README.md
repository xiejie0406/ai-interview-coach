直接用桌面浏览器打开 `index.html`，顶部切换三个项目。每个子目录也有可独立打开的 `index.html`。使用原生 HTML、CSS、JavaScript，本地图片和本地 Lucide 图标，不需要安装依赖、构建或运行服务器。

原型中的订单、客户、库存、价格、任务和运行结果均为示例。交互在当前浏览器中运行，支持本地状态保存；若浏览器禁止本地文件存储，则仅在本次打开期间保留。没有接入真实 ERP/MES、Agent、微信、1688 或推荐模型。

## 设计与实现范围

沿用现有 `admin-web` 的侧栏、面包屑、筛选条、数据表、详情抽屉和状态标签；参考 `prototype/interview-workbench-v1/` 的连续工作台布局。现有业务是 AI 面试，三项新业务的流程来自各自 PRD 和调研报告。

共用 `shared/base.css` 维护中性浅色画布、绿色主操作、蓝/琥珀/红语义状态、紧凑标题和 6px 圆角。主要业务页面直接作为首屏；不同项目保留甘特图、执行过程、商品搭配等各自主要内容。图标按钮有名称和提示，弹窗支持 Escape、焦点圈定及关闭后焦点恢复。

实施切片：共享样式与交互工具、三个独立业务原型、总入口与定向浏览器验证。文件改动仅在本目录。无生产依赖安装，无真实账号操作、业务写入或 Git 写操作。

参考产品逻辑回链：

- 排程：[调研](../../文档/项目/生产排产项目/调研/市场与竞品调研.md)，采用约束校验、人工调整、模拟/发布分离与现场反馈。
- Aden：[调研](../../文档/项目/智能体桌面端项目/调研/市场与竞品调研.md)，采用任务状态、外部等待、人工审批/接管和执行证据。
- 服装：[调研](../../文档/项目/智能选品项目/调研/市场与竞品调研.md)，采用商品池、可编辑 Look、硬条件校验与价格快照。

## 验证结果与边界

目标浏览器为 Chromium 桌面；定向检查 1440×1000 与 390×844 视口，并检查入口的窄屏切换。允许业务表格/甘特图局部横向滚动，页面整体不应横向溢出。

已通过 53 项页面/导航检查、13 组核心业务交互检查和 3 项报价交付检查。覆盖 21 个主要视图、关键状态变化、报价计算、实际 CSV 下载和刷新持久化；结果与截图单独维护在 [验证记录](verification.md)。打印检查指打印媒体下的页面布局，不表示已完成实体打印或所有纸张规格的分页验证。

本轮不验证真实排程求解质量、模型准确率、桌面控制可靠性、平台授权和生产系统接口，也不代表真实用户验收。发现问题时只修正本原型范围；无需保留的演示状态可清除浏览器本地存储，原始 PRD 和既有系统不受影响。

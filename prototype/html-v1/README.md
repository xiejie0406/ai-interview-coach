## 打开方式

这是无需安装依赖的静态 HTML 原型。直接双击 `index.html` 即可打开；若需要检查 hash 导航，可在任意静态服务器下提供该目录。浏览器验证命令、端口和截图结果须以本轮授权记录为准。

## 页面清单

- 公开区：产品首页、产品能力与使用流程、示例报告、Free/Pro 套餐、FAQ、登录/注册。
- 求职者工作台：新手引导、Dashboard、题库、题目详情、单题练习、专项练习、模拟面试配置、面试计划确认、文本面试室、语音面试室、暂停/恢复/主动结束、报告总览、逐题证据、弱项学习计划、复测趋势、套餐用量、账号隐私。
- 管理后台：题目/Rubric、创建编辑、审核发布、Provider 状态与成本、Golden Set、投诉纠错、删除请求、敏感访问审计。
- 产品决策中心：12 项 A/B/C 决策选择，选择只写入浏览器 `localStorage` Mock 状态。

## 交互与状态

顶部“状态实验室”可以切换首次进入、空、加载、局部加载、无结果、表单错误、未登录、无权限、Session 过期、麦克风拒绝/无设备、ASR/TTS/LLM 失败、低置信术语、转写修正、自动文本降级、断网/恢复、重复提交、暂停、主动结束确认、报告生成、证据不足、额度不足、删除处理中/部分失败和管理员 reason code 等状态。

语音室是明确的 Mock 状态链：麦克风说明 → 模拟授权 → 录音 → ASR 转写 → 低置信术语 → 用户修正 → TTS 播放 → TTS 失败 → 文本降级。不会调用 `getUserMedia`，不会录音、上传或调用 ASR/TTS/LLM。

## Mock 边界与未实现能力

- 页面、题目、Rubric、报告、用量、Provider 和管理员数据全部来自 `data/mock-data.js` 或内联 Mock。
- 不连接真实后端、数据库、支付、模型、ASR、TTS、对象存储、账号系统或审计服务。
- 不上传真实录音、简历、JD、隐私数据；不要在表单中填写真实信息。
- 不证明模型评分质量、语音延迟、删除 SLA、支付扣费、权限隔离、生产可靠性、合规或招聘效果。
- “练习反馈，不是招聘结论”；不提供真实面试隐蔽代答、悬浮提示或规避检测能力。

## 设计原则

遵循 `ui-ux-pro-max` 的 AI-native、WCAG AA、可见焦点、键盘可达、语义状态、44px 触控目标、窄屏无横向滚动、减少动效和语义色约束。中性色画布承载证据密度，紫色只用于主行动和选中态；错误/警告/成功同时使用文字与图标，不依赖颜色单独表达。

## 本轮运行与浏览器检查

- 静态服务：`python -m http.server 4173 --bind 127.0.0.1 --directory <html-v1>`；仅在本机回环地址运行，验证结束后已停止。
- 页面入口：公开区、求职者工作台、管理后台和决策中心共 32 个 hash 页面均存在唯一 `h1` 与 `main`；结果 `Pass`。
- 关键交互：首页到新手引导/Dashboard、题库筛选、文本暂停与主动结束确认、语音授权→录音→ASR→低置信术语→修正→TTS→失败→文本降级、决策 A/B/C 选择；结果 `Pass`。
- 响应式：1440×900 与 390×844 检查；关键页未出现页面级横向溢出或控件跑出视口，窄屏按钮/角色切换达到至少 44px 的实际目标；结果 `Pass`。
- 可访问交互：路由后焦点进入主要内容，表单有可见标签，状态区域使用语义文本与 `aria-live`；结果为原型范围 `Pass`，不等于完整 WCAG 审计。
- 控制台：最终 `error` / `warn` 均为 0；结果 `Pass`。
- 截图：`screenshots/01-home.png` 至 `09-mobile-voice.png`，覆盖首页、题库、文本面试、语音失败降级、报告、决策中心、管理后台与两个窄屏视图。
- 用户业务验收、真实 Provider、真实麦克风、评分质量、隐私删除、支付、权限隔离和生产性能：`NotRun`。

浏览器原型通过只证明本地 Mock 交互可用于产品评审，不能把 HTML 文件、截图或一次浏览器检查描述为已实现产品、生产能力或用户验收通过。

## 打开工作台

当前环境可在本目录运行 `node serve.cjs`，然后打开 **http://127.0.0.1:8768**。Windows 也可以运行 `powershell -NoProfile -File start.ps1`。已有 Node.js 即可，不安装依赖、不连接数据库，服务只监听本机；停止进程即可关闭。

请通过本地 HTTP 服务打开。直接双击 HTML 的 `file://` 模式会受到浏览器 Canvas 图片安全限制，无法保证图片和 PPT 导出。端口被占用时设置 `FASHION_PROTOTYPE_PORT` 为另一个本机端口再启动，不能沿用不同端口的浏览器存储来证明数据恢复。

## 建议体验路径

1. **工作概览 → 需求工作台**：查看示例客户，解析描述并确认数量、预算、风格和一至四档。预算留空表示不限；新建方案不带样例运费。
2. **搭配选品**：生成各档候选，锁定/解锁、换款、保持锁定重搭、调整顺序与尺码。预分配只是参考，正式报价前须核对客户尺码。
3. **图片工作室**：默认四件舒适优选可体验模特样例任务与复核；其他搭配可上传外部生成图。电商任务及拼版按钮会生成真实商品拼版。支持取消、失败重试及示例积分。
4. **报价确认**：核对尺码配比，设置备选或合并采购、优惠、费用、税费和有效期，应用条件后确认快照。示例四件100套、95折、300元运费为24,050.00元。
5. **方案交付**：切换历史版本，编辑企业模板、复制或作废报价；预览并下载真实可编辑PPTX、报价CSV和图片ZIP。历史金额和图片不随当前商品更新而改写。
6. **工作台设置 → 商品运营**：商品库新增/维护款色与尺码；数据导入下载模板后上传CSV/XLSX，检查差异再整批发布。价格、库存与客户价表互不覆盖。图片素材页上传京东插件下载文件，导入映射或手工核对主图。
7. **客户方案 / 客户管理 / 设置**：新建、复制和切换独立客户方案，设置客户价格表；下载完整备份，恢复备份。跨标签页的旧版本写入会被拒绝，保留当前输入。

## 已提供的本地能力

12个完整业务页面，真实本地CSV/XLSX/图片/ZIP处理，严格全量差异及错误清单、历史恢复，基于实际SKU的组合搜索与整数分报价，图片版本复核及演示任务，可持久化报价快照，真实PPTX/CSV/图片ZIP输出，模板、客户方案、角色场景、备份与异常恢复。

商品数据、品牌联系人和模特图均为虚构示例。图片素材使用内置imagegen生成，实际提示词及SKU对应见[素材来源](assets/SOURCES.md)。运行中的模特任务明确使用预置示例，未调用实时模型；商品拼版不是AI试穿。角色切换用于体验流程，生产权限须由服务端验证。

## 验证与复现

- `node core-test.cjs`：金额、税费、数量守恒、共享库存、时效、客户价、快照及恢复的独立规则测试。
- `node catalog-test.cjs`：CSV及商品域的严格全量、原子性、并发、客户价表与恢复测试。
- `node browser-test.cjs`：主流程、下载、刷新、响应式和浏览器错误检查。
- `node catalog-browser-check.cjs` / `node extended-browser-check.cjs`：实际文件与扩展业务操作。
- `node delivery-check.cjs` / `node delivery-browser-check.cjs`：PPTX结构、页面几何、文件下载、生命周期与合并报价。
- `node studio-browser-check.cjs`：图片任务、额度、外部上传和电商拼版。

浏览器脚本使用当前电脑捆绑Playwright与独立无登录Chrome，每次临时创建127.0.0.1测试服务并结束关闭；换电脑需调整脚本顶部运行时路径。原型运行本身没有这些测试依赖。

最终结果及REQ/AC证据以[项目验证记录](../../文档/项目/智能选品项目/原型/服装工作台原型验证记录.md)和[需求映射](verification/requirements-map.md)为准。截图只证明实际检查的页面；PPTX结构与同源预览不能代替未执行的PowerPoint/WPS桌面兼容测试。

## 生产接入边界

PRD保留完整生产要求与32项验收条件。本原型完成业务交互与本地实际文件闭环；真实ERP/数据库、多用户服务端鉴权、京东账号采集适配、付费模型、供应商四SKU保真测试、生产容量/备份恢复和部署发布应按实施规格的TASK08接入并取得真实证据。当前未执行客户发送、生产写入、付费模型调用或发布。

本地图片会生成适合演示的预览，不作为原始高清资产库；原文件保留在用户电脑。生产文件容量和原型容量分别说明，不将浏览器存储容量当作生产能力。
